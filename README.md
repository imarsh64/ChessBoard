## Electronic Chess Board
Version 1 of this chessboard will be a chessboard will hall sensors to detect the chess pieces. When a piece is picked up, the board will light up the squares with legal moves. Version 1 will just be an over the board version (ie both players are using the board in person). The board will detect when there is a winner.

Later I would like to add connection to a service like lichess to allow playing bots or other players online while using the board
